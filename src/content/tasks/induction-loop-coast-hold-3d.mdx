## Task Brief

Set the five interior knots of the field program, run a test to observe the loop's coast, and submit a passing test. The episode allows up to 48 calls, including invalid calls.

## Run on Linux

Install the mod under the official AgentArk 1.0.6 Linux Player's `AgentArk_Data/Resources/Mods/all_tasks/InductionLoopCoastHold3D` directory. Follow `launch/LAUNCH.md` and use the included launcher to select a seed and partition. The qualification backend uses Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, and Pillow 12.3.0.

The launcher runs qualification before opening a scored episode. It accepts `--qualification-wall-timeout-s 3600` on Linux. The first observation has no image. Paid observations arrive at 1600 × 720.

The r3 Linux mod completed a nine-call validation replay with reward +1.
