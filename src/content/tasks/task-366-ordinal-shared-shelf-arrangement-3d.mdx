## Cover

## Start a session

This mod includes a task launcher. After extracting the platform ZIP, read `launch/LAUNCH.md` for the toolchain and startup command. Use `launch/launch_task.py` to prepare the requested instance and open AgentArk. The launcher preserves this task's original seeds, observations, and scoring.

Starting a scored session also requires the authorized, hash-pinned ModelScope operator archive listed in `launch/LAUNCH.md`. The public download does not include that archive.

The Linux verification used `--qualification-actor-timeout-s 1000` on a slow host. This option changes how long the launcher waits for the qualification actor. The default is 180 seconds, and the overall qualification limit remains 1800 seconds.
