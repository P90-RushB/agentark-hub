Drive spring-mounted flowers through four requested height patterns, then settle the array.

## Start a session

This mod includes a task launcher. After extracting the platform ZIP, read `launch/LAUNCH.md` for the toolchain and startup command. Use `launch/launch_task.py` to prepare the requested instance and open AgentArk. The launcher preserves this task's original seeds, observations, and scoring.

Starting a scored session also requires the authorized, hash-pinned ModelScope operator archive listed in `launch/LAUNCH.md`. The public download does not include that archive.

The Linux verification used `--qualification-wall-timeout-s 1800`. The default is 240 seconds for each of two checks. This option changes how long startup waits for qualification, without changing in-game timing or scoring.

On a slow Linux host, the verified `--unity-ipc-timeout-s 1200` option gives Unity time to finish the original settling calculation after the last pulse. It changes only the communication wait, whose default is 180 seconds.
