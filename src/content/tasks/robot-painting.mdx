## Give the robot a target

A model observes camera images, plans a painting, and controls a simulated robot arm to move the brush across the canvas. Each stroke requires spatial reasoning, tool orientation and visual feedback.

**Robot Painting is Task 107 in AgentArk.** Its dedicated benchmark, [RoboPaintBench](https://robopaintbench.org/), provides published model records, paintings, videos and reproducible configurations. The [GitHub repository](https://github.com/P90-RushB/robopaint-bench) contains the source, setup guides and replay tools.

## Three ways to paint

- **Paint from a reference.** The Golden Gate Bridge track asks the model to interpret and recreate a supplied image.
- **Paint from words.** The Pelican track supplies only the instruction, “Paint a pelican riding a bicycle.” The model still observes the robot and canvas through camera images.
- **Bring your own target.** Supply a reference image, a text prompt, or both for a new model painting session. See the [custom painting guide](https://github.com/P90-RushB/robopaint-bench/blob/main/docs/custom-painting.md).

Prefer your own machine? The [Windows and Linux setup guide](https://github.com/P90-RushB/robopaint-bench/blob/main/docs/local-setup.md) covers the compatible Player, task installation, replay and viewing the environment. A Unity Editor installation is not required.

## One environment, one harness

The published benchmark uses AgentArk's built-in **SimpleAgent** for every model. OpenRouter, Volcengine and the Codex SDK are provider interfaces to the same harness.

Each session has **three connected in-context learning rounds**, with up to **96 actions per round**. A new canvas starts each round while experience carries forward in the session. These are sequential learning rounds rather than three independent trials.

The benchmark freezes one configuration; the environment also supports other brush, pigment and canvas settings. The [configuration guide](https://github.com/P90-RushB/robopaint-bench/blob/main/docs/environment.md) explains how to change them for custom experiments.
